# Laboration 1: Konceptuell datamodellering

**Kurs:** DT076G / DT139G – Databaser, modellering och implementering  
**Namn:** Emil Larsson

## Beskrivning
Denna labb innehåller ett ER-diagram för ett rikstäckande filmuthyrningsföretag. Modellen är utformad utifrån verksamhetsbeskrivningen i instruktionerna och täcker hantering av:
* Butiker, anställda och medlemmar
* Filmer, genrer och filmpersonal
* Butiksspecifika lagersaldon och priser
* Uthyrningar, reserveringar och betygsättning

## Projektstruktur
* **er-diagram.md:** Innehåller ER-diagrammet skrivet i Mermaid.
* **dokumentation/antaganden.md** Dokumentation av antaganden som diagrammet är grundat utefter.
